# Mischief Next Door

A landscape slapstick stealth-prank game for Android and iOS (Godot 4.7). Sneak around your grumpy
neighbour's house while the hidden cameras roll, set up pranks along his daily routine, don't get
caught, and make the studio audience howl.

Status: in development. See `docs/` for the design and progress. Developer commands are in `CLAUDE.md`.
