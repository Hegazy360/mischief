# Mischief Next Door

A landscape slapstick stealth-prank game for Android and iOS (Godot 4.7). A silent street mime takes revenge on
the loudest man alive: sneak around your grumpy neighbour's side-view house, rig his daily routine with slapstick,
freeze in plain sight, and bring the house down for a live theatre audience.

Status: in development. See `docs/` for the design and progress. Developer commands are in `CLAUDE.md`.
