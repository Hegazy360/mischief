# Clip events — every sound inside a clip (ruling L12)

_Generated by `tools/audio/clip_events.py` (rewritten by `tools/scripts/gen_audio.sh`; do not edit by hand). Owner: `s2-sound`. The anim tasks place these rows; `cues.json` no longer plays any of them, so a missing event is silence._

Each row is one clip event `{"f": f, "type": "sfx"|"voice", "id": id}` (+ `"vol_db"` when not 0). Frames are clip frames at 60 fps (view time: a hit-stop holds them); put each on its contact frame ± 1 f. `len_f` = the sound's length in frames (the longest take of a bank), to check it fits the beat. Ids resolve through `game/audio/sfx_map.json`; a voice id plays in the Settings `voice_style` automatically. Machine-readable copy (same rows, the one the tests parse): `game/data/audio/clip_events.json`.

Rows are sorted by phase: **G** = land now (Gate 0), **M** = batch 2.
