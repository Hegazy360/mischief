# tools/art/house — generators for the house, props, icons and the stage (art-house)

Everything under `game/art/house/**`, `game/art/icons/activities/**` and `game/data/house/house.json` is
generated by these scripts (deterministic; re-run after any change). Rules: `game/art/STYLE.md`.

| File | What |
|---|---|
| `geo.py` | THE layout: rooms, links, stations (GDD §7.1 x ± 80), hotspot hit boxes, stacks, landings, entries, station moves |
| `canon.py` | TECH §14 canonical ids (checked against docs/TECH.md by the lint) |
| `svgk.py` | SVG element kit: world-coord elements with bboxes, 1-decimal serialisation, outline growth, palette reducer, icon fit |
| `pal.py`, `draw.py` | palette/materials; cartoon helpers (shaded boxes/blobs, knobs, sparkles, Hush's hidden eyes, gloves) |
| `arch.py` | room architecture: walls, patterns, cornice, dado, wainscot, skirting, floor strip, slab, partition bands + doorways |
| `rooms_final.py` | final backgrounds: porch, hall (staircase), parlour (window, fireplace), kitchen |
| `rooms_grey.py` | greybox backgrounds: landing (stairwell), bathroom, bedroom, dressing, conservatory, garden |
| `props_base.py` | prop pipeline: states → shared-origin canvases + `_ol` outline sprite → registry (+ atlas budget) |
| `props_hall.py`, `props_parlour.py`, `props_kitchen.py` | final slice props, every state |
| `props_grey.py` | greybox hotspot props for the other rooms |
| `icons_items.py`, `icons_activities.py` | 16 item icons (128 px), 34 activity/detour icons (88 px) |
| `stage.py` | curtain, valance, proscenium, apron, footlight glow, flies, vignette, velvet rope, sky flats, roofs |
| `house_json.py` | builds `game/data/house/house.json` (TECH §4.1 + the art placement fields, STYLE §8) |
| `build_all.py` | runs everything (`--report` prints the per-room prop atlas budget) |
| `validate_svg.py` | SVG rule checker (STYLE §1: elements, gradients, ≤ 10 colours, margins, sizes, 1-decimal) |
| `lint_rects.py` | hotspot lint (≥ 144 px, 24 px gaps, no overlaps, stacks, ids ⊇ TECH §14, stations ± 80 px, art exists) |
| `compose.py`, `sheets.py` | Pillow review compositor + icon contact sheets (docs/review/art-house/) |

    python3 tools/art/house/build_all.py --report && python3 tools/art/house/validate_svg.py && python3 tools/art/house/lint_rects.py
